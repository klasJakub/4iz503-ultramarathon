# 4iz503-ultramarathon

Tento projekt je součástí předmětu **4IZ503 Projektový seminář** na VŠE v Praze (Fakulta informatiky a statistiky, vedlejší specializace Datové inženýrství).

Projekt se zaměřuje na analýzu a zpracování dat z ultramaratonských běhů.

## 📁 Struktura projektu

Projekt je organizován následovně:

* **`data/`** – Složka pro uložení vstupních CSV souborů (ignorováno gitem via `.gitignore`).
* **`notebooks/`** – Jupyter notebooky pro analýzu a modelování.
  * `01_priprava_dat.ipynb` – Načtení, čištění a příprava dat.
* **`outputs/`** – Složka pro exportované vizualizace, grafy a výsledné datasety.
* **`README.md`** – Tento průvodce projektem.
* **`.gitignore`** – Definice ignorovaných souborů.
