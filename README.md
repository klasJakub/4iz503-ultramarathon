# 4IZ503 — Analýza ultra-maratonských dat

## Popis
Semestrální projekt předmětu **4IZ503 (Projektový seminář)** na VŠE v Praze (Fakulta informatiky a statistiky, vedlejší specializace Datové inženýrství).

Projekt se zaměřuje na analýzu, čištění a modelování dat z ultramaratonských běhů s cílem odhalit zajímavé souvislosti a vzorce v chování běžců.

## Data
**The Big Dataset of Ultra-Marathon Running**  
Zdroj: [Kaggle Dataset](https://www.kaggle.com/datasets/aiaiaidavid/the-big-dataset-of-ultra-marathon-running)  
*Poznámka: Vzhledem k velikosti nejsou datové soubory součástí repozitáře.*

## Nástroje
- **Python** (knihovny `pandas` pro zpracování dat a `CleverMiner` pro asociační pravidla / datamining)
- **Power BI** (pro interaktivní vizualizaci a reporting)

## Struktura projektu
- **`notebooks/`** — Jupyter notebooky s analýzou a modelováním
  - `01_priprava_dat.ipynb` — Načtení, čištění a příprava dat pro další analýzu
- **`data/`** — datové soubory (jsou lokálně ignorovány via `.gitignore` a nejsou součástí repozitáře)
- **`outputs/`** — složka pro exportované vizualizace, grafy a výsledné datasety
